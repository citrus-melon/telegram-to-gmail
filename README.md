# Telegram to Gmail

This is a Google Apps Script/webhook based-Telegram bot that forwards messages from Telegram channels to Gmail.

## Features
### Rich Message Mapping
Maps rich text formatting and common non-interactive attachment types

### Telegram Mini App configuration interface
Minimal Telegram Mini App that allows configuration of:
* Users permitted to modify configuration
* Any number of mappings from Telegram channel to recipient address
* Temporary on/off

### Google Apps Script
Hosted completely in Google Apps Script; easy setup and no other infrastructure required
